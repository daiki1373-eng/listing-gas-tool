# リスティングCSV → PowerPoint（GAS版）

リスティング広告のCSVを読み込み、実績・日予算・キーワード分析を編集可能なPowerPointにまとめるWebアプリです。Google Apps Script の HTML Service で配信できます。アプリのバージョンは **v1.8** です。

## 別のPC・GASで使う

テンプレートを含む配布用ZIPでは、展開後に **`start.html` を開くだけ**で、CSVからPowerPointを作成できます。Python・Node.js・Googleへのログインは不要です。

GitHub版や新しいGASでは、画面の「PowerPointテンプレート」から対応PPTXを選択できます。テンプレートをDriveへ登録する方法も引き続き利用できます。[別PC・別GASでの導入手順](docs/別PC・別GASで使う.md)を参照してください。

## v1.8のレイアウト修正

日別表の行高・段落書式を統一し、PowerPointで開いたときに下端が押し出される問題を修正しました。表は全行を一度ずつ出力し、各ページに対象日付・行番号・続きのページ番号を表示します。

長い日別グラフは1ページ最大20行で均等に分け、前ページの最終日を次ページの先頭にも表示します。日別表も最後のページだけが少数行にならないよう均等に分割します。各指標の縦軸は全ページで共通です。日付ラベルを短くし、値が0以上の指標は縦軸の最小値を0にします。

## 主な機能

- 設定・月別・日別・時間別・日予算ログ・キーワード・時間帯×曜日別CSVの一括取込と自動判別。
- UTF-8、UTF-16 BOM、Shift-JIS / CP932の入力に対応。
- 初期条件は費用1円以上。表示回数・クリック数・応募数・アクション数の下限も指定可能。
- 日予算の到達率・到達時刻の分析。長い期間は自動で改ページ。
- キーワード流入サマリーと費用順の上位キーワード分析。
- 時間帯×曜日のヒートマップ、時間帯別・曜日別の編集可能なグラフ。
- 既存テンプレートのレイアウトを使ったPPTX出力。長文の折返し・表の改ページ・末尾空行の整理。

CSVの内容、分析結果、出力PPTXはブラウザー内で処理します。GASサーバーは登録されたPPTテンプレートの読み取りに使用します。

## GASへの導入

1. **このツールに対応する原本PPTテンプレート2種類**を用意します。Driveから読み込む場合は、ファイル名を `ListingTemplateSingle.pptx` と `ListingTemplateMulti.pptx` にしてGoogle Driveへアップロードします。PPTXのまま保存します。
2. Apps Scriptプロジェクトに `gas/Code.gs` を保存します。HTMLファイルを **Index** という名前で作成し、`gas/Index.html` 全体を保存します。
3. `gas/appsscript.json` を参考に、必要なDrive読み取りスコープを設定します。既存プロジェクトでは他の設定・スコープを保持してください。
4. `Code.gs` 冒頭の `REPORT_TEMPLATE_IDS` にテンプレートのDrive IDを設定するか、`setupReportTemplates` を一度実行してファイル名から登録します。画面上で対応PPTXを選択して利用する場合はDriveへの登録を省略できます。
5. ウェブアプリとしてデプロイし、実行ユーザーを自分、利用範囲を必要な範囲に設定します。まずは **自分のみ** で確認できます。
6. 発行されたWebアプリの `/exec` URLを開きます。`file:///.../gas/Index.html` からはGASのテンプレート取得を実行できません。

**PPTテンプレート本体は、この公開リポジトリには含めていません。** 任意の空のPPTXでは動作しません。元の対応テンプレートのスライド構成・図形名・表・グラフを利用するため、互換性を保った原本を別途用意してください。Googleスライドへの変換は不要です。

既存GASを更新する場合は、編集したファイルを保存後、既存デプロイを **新バージョン** に更新します。公開リポジトリにしたことによって、GASのアクセス範囲が変わることはありません。

## CSVの使い方

1社・1アカウント分をまとめて読み込みます。日別・時間別・日予算ログ・時間帯×曜日別は、それぞれ別ファイルのままで構いません。宛名と集計期間を確認し、PowerPointを作成します。

時間帯×曜日別CSVの例：

```csv
時間帯,曜日,表示回数,クリック数,売上,ctr,アクション数,atr,cvr
0時~8時,月,100,1,40,0.01,0,0,0
```

- 時間帯は `0時~8時` / `8時~16時` / `16時~24時`、曜日は月～日に対応します。
- この形式の `売上` は配信費用として扱います。
- `時間別実績` 欄へ入れた場合も、中身から時間帯×曜日別として判定します。
- 初期指標はクリック数です。応募数の列がない場合に応募数を選ぶと、クリック数×CVRによる推計値を表示します。
- CTR・ATRは分子と分母の合計から算出します。応募数がない場合のCVRはクリック数で加重平均します。
- 未観測の組合せは `—` で表示します。CSVに期間がなければ、別CSVの期間を流用しません。

除外条件はANDで適用します。そのCSVに存在しない指標の条件は適用せず、画面に案内します。日予算の到達率は元の分析期間と全到達ログから計算し、明細のみ絞り込みます。

KWと日別実績の対象期間が一致しない場合、キーワード内の構成比は表示しますが、全体費用に対する比率は表示しません。

## ソースの編集と確認

必要なランタイムは **Python 3.9以上** と **Node.js 20以上** です。ビルドと回帰テストに追加パッケージは不要です。

```sh
python scripts/build.py
python -m unittest discover -s tests -p "test_*.py"
node --test tests/core.test.mjs tests/templates.test.mjs tests/report-flow.test.mjs
```

`src/` を編集してビルドし、更新された `gas/Index.html` をGASへ反映してください。GitHubへのpushだけではGASには自動デプロイされません。

`src/index.html` や `gas/Index.html` をローカルで開き、画面から対応PPTXを選択する方法でも出力できます。テンプレートを同梱した `start.html` では、この選択も不要です。

原本2つを `private/templates/` に置いた後、次のコマンドで別PC用の一式を作れます。ファイル名や詳細は[導入手順](docs/別PC・別GASで使う.md)を参照してください。

```sh
python scripts/package.py --templates-dir ./private/templates --output ./dist/listing-gas-tool-portable.zip
```

## 公開用データの扱い

実際の顧客CSV・顧客資料・出力見本・PPT原本・導入先URL・アカウント固有のDrive IDは含めていません。`examples/` は架空データです。認証情報や `.clasp.json` などのローカル設定をコミットしないでください。
